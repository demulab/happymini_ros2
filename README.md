# Happy Mini ROS2 Repository

This repository provides the software environment for developing and operating **Happy Mini**, a mobile robot developed by Demura Laboratory, using **ROS2 Humble**.  
It also includes software modules designed for participation in the **RoboCup@Home** competition.

## Overview

Happy Mini is an educational and research-oriented robot platform aimed at learning practical robot programming, navigation, and human–robot interaction.  
This repository contains:

- ROS2 Humble packages for controlling the Happy Mini robot  
- Navigation and perception modules  
- Sample applications for RoboCup@Home tasks  
- Utilities for simulation and real-robot experiments

## Main Features

- Mobile base control and teleoperation  
- SLAM and autonomous navigation  
- Object recognition and manipulation interfaces  
- Task programs for RoboCup@Home challenges  
- Simulation support using Gazebo

## Requirements

- Ubuntu 22.04  
- ROS2 Humble  
- Additional dependencies listed in `package.xml`
